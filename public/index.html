Setup Guide

Step-by-step instructions for connecting every service to StudyPulse. You'll need to log into each one yourself to get the credentials — but this tells you exactly what to click.

🔵
Canvas LMS — API Token
Required to sync your assignments automatically
REQUIRED
1

Go to your school's Canvas

Open your browser and go to your Canvas URL — e.g. somsd.instructure.com — and sign in with your school account.

2

Open Account Settings

Click your profile picture / initials in the top-left corner → click Settings.

3

Scroll to Approved Integrations

Scroll down the Settings page until you see the Approved Integrations section. Click + New Access Token.

4

Create the token

In the Purpose field type StudyPulse. Leave the expiry date blank (so it never expires). Click Generate Token.

5

Copy it immediately

⚠️ Canvas only shows the token once. Copy it now and go to the 🔵 Canvas Sync tab and paste it there.

📧
Resend — Email Reminders
Sends your daily and weekly HTML digest emails · Free forever
REQUIRED
1

Create a free account

Go to resend.com → click Get Started Free → sign up with any email. No credit card needed.

2

Go to API Keys

In the left sidebar click API Keys → click Create API Key → name it StudyPulse → click Add.

3

Copy the key

It starts with re_. Copy it and go to the 📧 Email Reminders tab and paste it there along with your email address.

4

Send a test email

Click Save Settings then Send Test Email to confirm it works. Check your inbox.

✨
Anthropic — AI Reminders
Powers the AI-written reminder messages and coaching notes · Optional
OPTIONAL
1

Create an Anthropic account

Go to console.anthropic.com → sign up. You get free credits to start — no card required initially.

2

Get an API key

In the console, go to API Keys → click Create Key → name it StudyPulse → copy the key (starts with sk-ant-).

3

Add it to your .env file

Open the .env file in your StudyPulse folder and add: ANTHROPIC_API_KEY=sk-ant-yourkey. Restart the server. AI reminders will activate automatically.

💬
Slack — Channel Reminders
Posts assignment reminders to a Slack channel or DM · Free
OPTIONAL
1

Go to api.slack.com

Sign in with your Slack account → click Create an App → choose From scratch → name it StudyPulse → pick your workspace.

2

Enable Incoming Webhooks

In your app settings, click Incoming Webhooks in the left sidebar → toggle it On.

3

Create a Webhook

Scroll down → click Add New Webhook to Workspace → pick the channel you want reminders in (or pick a DM with yourself) → click Allow.

4

Copy the Webhook URL

Copy the URL that appears — it starts with https://hooks.slack.com/services/

5

Add it to StudyPulse

Open the .env file and add: SLACK_WEBHOOK=https://hooks.slack.com/services/yoururl then restart the server.

🔔
ntfy — Phone Notifications
Instant push notifications to your phone · 100% free, no account needed
OPTIONAL
1

Download the ntfy app

Search ntfy on the App Store (green icon) or Google Play — it's free. Install it.

2

Subscribe to your topic

Open ntfy → tap + → tap Subscribe to topic → type studypulse-devan → tap Subscribe.

3

Enable notifications

Allow notifications when prompted. Go to iPhone Settings → Notifications → ntfy → make sure Allow Notifications is on.

📱
Brevo — SMS via T-Mobile Gateway
Alternative SMS method using email-to-text gateway · Free 300/day
OPTIONAL
1

Create a free Brevo account

Go to brevo.com → sign up free → complete the onboarding survey (choose Personal, Technology, under 1,000 emails/month).

2

Find your SMTP credentials

Go to Settings → SMTP & API. You'll see your SMTP Login (looks like a12345@smtp-brevo.com) and a button to generate an SMTP Key.

3

Generate the SMTP Key

Click Generate a new SMTP key → name it StudyPulse → copy the long key that appears.

4

Enable SMS in T-Mobile

Make sure Email to Text is enabled on your T-Mobile account. You can check this in the T-Mobile app under Account → Add-ons, or call T-Mobile support.
